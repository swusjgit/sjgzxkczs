# 图灵测试实验

来源：用户提供的 `图灵测试.html`。保留原有题库和“寻找人类 / 寻找 AI”两种模式，通过首页“图灵测试”入口打开。

页面的样式、动画库和原背景图片均保存在本目录，运行时不需要加载原第三方资源域名。

- `turing-utilities.css`：从原页面使用的 Tailwind CSS 3.4.17 生成，保留 MIT 许可标识。重新生成时须包含脚本中动态添加的颜色类。
- `anime-3.2.1.js`：原页面使用的 anime.js 3.2.1，保留作者和 MIT 许可标识。
- `background.png`：原页面背景，原地址虽然以 `.jpg` 结尾，但实际为 PNG。

- 样式生成工具：`https://metis-online.fbcontent.cn/metis-misc/zgLDUdmazTYc0B4K6Cor.js`
- 动画库：`https://metis-online.fbcontent.cn/metis-misc/zZZY40t7WJC7UdQCPACm.js`
