# AI 时光机

来源：用户提供的 `AI时光机.html`，保留六个历史节点、语音解说、知识挑战和通关徽章。首页入口位于“图灵测试”上方。

- 图片和六段语音位于 `assets/`，均来自原文件引用的素材。图片转换为 WebP，最长边不超过 1200 像素。
- `time-machine-utilities.css` 从原页面的 Tailwind CSS 3.4.17 生成，覆盖时间线节点、答题反馈、已完成状态和通关徽章。保留 MIT 许可标识。
- 动画库复用 `../图灵测试/anime-3.2.1.js`，保留其作者和 MIT 许可标识。
- 活动运行不需要加载原第三方素材域名。“AI工具搜索”是原页面保留的可选外部导航。
- 接入时增加了返回课程助手入口、键盘可操作的时间线节点，并修正手机详情页滚动和答题反馈颜色。

重新生成样式时，须保留原 Tailwind 主题中 `space`、`neon`、`cyber` 和动画的定义，并包含脚本动态添加的颜色类。

原资源来源：`metis-online.fbcontent.cn`、`musk-online.fbcontent.cn`。
